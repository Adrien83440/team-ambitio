🎯 Cibles & repères

Bornes utilisées pour les badges vert / orange / rouge sous les KPIs. Laisser vide = pas de repère. Stocké dans _config/funnel_targets.

💶 Coûts setting (réels)

Alimente le Coût / RDV NB : (fixe + commissions Setting + outils) ÷ RDV posés par le setting. Les commissions viennent automatiquement du module Commissions (deals Setting datés dans la période) — seuls le fixe (salaire setter) et les outils (Ringover, Twilio…) sont à renseigner ici, en €/mois. Une valeur saisie pour un mois est reportée automatiquement sur les mois suivants tant qu'une valeur plus récente n'est pas saisie. Stocké dans _config/funnel_costs.

🔗 Accès agence — lecture seule

Un lien secret que l'agence pub peut ouvrir quand elle veut, sans compte ni accès Firestore. Elle ne voit QUE les KPIs marketing du mois (pub, opt-in, prise de RDV, créatives, rentabilité, Instagram organique, journal) — jamais un nom de lead, un montant de commission, un coût interne, ni le pseudo d'un commentateur Instagram ou le contenu d'un message privé. Instagram est inclus en chiffres agrégés : audience, GO par publication, taux de réponse aux DM. Les chiffres sont l'instantané publié à chaque consultation du funnel en vue Mois / Tous les tunnels. Stocké dans _config/agency_access.
