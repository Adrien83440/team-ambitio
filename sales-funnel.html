🎯 Cibles & repères

Bornes utilisées pour les badges vert / orange / rouge sous les KPIs. Laisser vide = pas de repère. Stocké dans _config/funnel_targets.

💶 Coûts setting (réels)

Alimente le Coût setting (fixe + outils + commissions de setting dues) et le Coût / RDV pris NB : (fixe + outils + commissions des closes Setting (NB)) ÷ RDV pris NB (= Sets). Les commissions sont lues dans le module Commissions (closes de la période, validées ou non) — seuls le fixe du setting et les outils (Ringover, Twilio…) se renseignent ici, en € hors taxes par mois. Le fixe n'est pas lu dans les contrats de l'équipe (la page Commissions, elle, les lit) : vérifie qu'il correspond. Une valeur saisie pour un mois est reportée automatiquement sur les mois suivants tant qu'une valeur plus récente n'est pas saisie ; sur un mois en cours, elle est comptée au prorata des jours écoulés. Stocké dans _config/funnel_costs.

🔗 Accès agence — lecture seule

Un lien secret que l'agence pub peut ouvrir quand elle veut, sans compte ni accès Firestore. Elle ne voit QUE les KPIs marketing du mois (pub, opt-in, prise de RDV, créatives, rentabilité, Instagram organique, journal) — jamais un nom de lead, un montant de commission, un coût interne, ni le pseudo d'un commentateur Instagram ou le contenu d'un message privé. Instagram est inclus en chiffres agrégés : audience, GO par publication, taux de réponse aux DM. Les chiffres sont calculés à la demande, par le même module que cette page, pour la période qu'elle choisit. Stocké dans _config/agency_access.

👁 Accès lecture — liens par personne

Un lien par personne : il ouvre CE module en lecture seule (tous les onglets, noms des leads, questionnaires), sans compte ni mot de passe. Jamais les transcriptions / résumés / analyses des visios, ni le détail des commissions, ni aucune écriture. Désactiver ou laisser expirer coupe l'accès en quelques secondes, page ouverte comprise. Chaque ouverture de page est journalisée (date, durée, ville, appareil).
